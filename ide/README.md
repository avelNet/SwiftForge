# SwiftForge Desktop

Первая ветка IDE содержит настольную оболочку на Tauri 2, React и Monaco. В ней можно открыть локальную папку, раскрывать каталоги, переключать файлы и сохранять изменения. Monaco подсвечивает Swift, YAML, JSON и Markdown. Панель iPhone показывает AirPlay-поток внутри IDE. Подсказки SourceKit и сборка IPA идут отдельными ветками по [плану MVP](../docs/mvp-architecture.md).

## Запуск на Ubuntu

Нужны Node.js 22.12+, npm, Cargo, компилятор C и системные [зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/#linux).

```bash
cd ide
npm ci
npm run tauri -- dev
```

Для запуска сборки со встроенными статическими ресурсами:

```bash
npm run tauri -- build --debug --no-bundle
./src-tauri/target/debug/swiftforge
```

В **Open folder** выберите копию `ios-probe/SDKProbe`. Раскройте `Sources/SDKProbe`, откройте `ContentView.swift`, измените текст и нажмите **Ctrl+S**. При удалении файла или изменении его внешним инструментом редактор покажет ошибку сохранения. Дерево фильтрует скрытые каталоги, `node_modules` и символические ссылки. В текущей версии открываются UTF-8-файлы размером до 2 МиБ.

**Ctrl+O** открывает папку, **Ctrl+B** скрывает или показывает дерево проекта. Поиск в открытом файле доступен через значок лупы или **Ctrl+F**. Перетаскивайте границы рядом с редактором, чтобы изменить ширину дерева и панели iPhone. Граница также поддерживает стрелки после фокусировки клавишей Tab. Панель iPhone можно скрыть значком телефона. Активное зеркалирование продолжится, и значок сохранит индикатор приёмника.

## Панель iPhone

На Ubuntu понадобятся UxPlay, GStreamer, декодер H.264 и плагины для JPEG и локального TCP. Пример установки из репозитория Ubuntu:

```bash
sudo apt install uxplay gstreamer1.0-tools gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-plugins-bad gstreamer1.0-libav
```

Запустите SwiftForge, нажмите **Start mirroring** и на iPhone в той же локальной сети выберите **Пункт управления → Повтор экрана → SwiftForge IDE**. Введите PIN из панели. **Stop mirroring** завершает локальные процессы и очищает изображение. Звук выключен. Управление приложением остаётся на телефоне.

SwiftForge запускает UxPlay как отдельный процесс. Внутри UxPlay GStreamer декодирует H.264. В окно Tauri передаются JPEG-кадры по локальному TCP на `127.0.0.1`. Сохраняется только последний кадр в оперативной памяти. Для локально распакованного UxPlay укажите абсолютный путь в `SWIFTFORGE_UXPLAY`. Если приёмник не появляется на iPhone, проверьте, что устройства находятся в одной локальной сети и Avahi запущен.

Если процесс UxPlay завершился, панель покажет причину и снова предложит **Start mirroring**. После перезапуска приёмника подключите iPhone заново. При короткой паузе в потоке панель сохраняет последний кадр и отмечает, что ждёт обновления.

## Создание и сборка приложения

**New project** или **Ctrl+N** создаёт новый SwiftUI-проект, пригодный для `xtool`. Мастер создаёт отдельную папку, `Package.swift`, `xtool.yml` и исходники. Существующую папку он не перезаписывает.

Для сборки добавьте Swift и `xtool` в `PATH` перед запуском IDE. SDK устанавливается через `xtool sdk install` из официального локального архива Xcode. **Build** запускает `xtool dev build --ipa` с текущей конфигурацией. **Build output** показывает журнал. **Toolchain** проверяет версии и SDK, **Export IPA** открывает диалог сохранения сборки.

## Подсказки Swift

Установите Swift 6.4 с `sourcekit-lsp` и добавьте его в `PATH`. Для проектов с `xtool.yml` IDE создаёт локальную конфигурацию BSP, если её ещё нет. Строка состояния показывает запуск SourceKit. Monaco отображает автодополнение, сигнатуры, документацию символов, диагностические сообщения и переходы к определениям в пределах проекта. После холодного открытия iOS-проекта SourceKit может сначала показать ошибки импорта, пока получает настройки от BSP.

## Меню, настройки и GitHub

Верхнее меню разделяет действия над файлами, редактором, видом, сборкой и GitHub. **Ctrl+,** открывает настройки. Тема, размер шрифта, отступ, перенос строк и миникарта применяются сразу и сохраняются локально.

**GitHub → Clone repository** открывает рабочую копию публичного репозитория по ссылке или в формате `owner/repository`. **Repository status** выводит Git-статус, **Open origin on GitHub** открывает страницу origin. Клонирование использует установленный Git. Поддержка сборки зависит от формата проекта. Для текущего пути требуются SwiftPM и `xtool.yml`.

## Установка и логи физического iPhone

Для USB-статуса и логов нужны `usbmuxd` и `libimobiledevice-utils`. Подключите разблокированный iPhone и обновите USB-статус в панели. После сборки **Install via iLoader** сохраняет IPA и открывает iLoader. Выберите сохранённый файл в iLoader и подтвердите подпись и установку там. Для отдельно установленного iLoader задайте `SWIFTFORGE_ILOADER` с абсолютным путём к его исполняемому файлу.

Кнопка **Logs** читает USB-логи процесса, имя которого получено из имени собранного IPA. Вывод идёт в общую нижнюю панель. AirPlay и USB управляются отдельно.

## Терминал

Откройте **View → Show terminal** или панель со значком терминала. Оболочка запускается из папки проекта в PTY. Скрытие панели сохраняет сессию. При смене проекта IDE завершает терминал предыдущей папки. **Restart terminal** открывает новую сессию.
