# Проверка внешнего SwiftUI-проекта

- Проект: [erion062/LEDAP](https://github.com/erion062/LEDAP).
- Исходный коммит: `eda1b12e219468f5d96a9ac5b551f6fbaaf921cf`.
- Среда: Ubuntu 26.04.1, Swift 6.4.2, xtool 1.24.0, SDK из Xcode 27.2.
- Формат: готовый SwiftPM-проект с `xtool.yml`, собственным Info.plist и иконкой.
- В настольном окне SwiftForge выполнены клонирование с GitHub, открытие `HomeView.swift`, изменение заголовка на `SwiftForge LEDAP`, сохранение и сборка IPA.
- Архив проверен, исполняемый файл имеет заголовок Mach-O ARM64.
- SHA-256 неподписанного IPA: `3934eb046bc27b77475ba694b0c5a1c99ad6203c8d207b87142d611a950c18d1`.
- После освобождения одного места бесплатной подписи iLoader установил IPA. По USB подтверждены пакет LEDAP 1.0.0 и запущенный процесс LEDAP. На вкладке Lights владелец iPhone подтвердил изменённый заголовок «SwiftForge LEDAP».

Отдельные прогоны нативного окна подтвердили создание SwiftUI-проекта и сборку IPA, диагностическую подсветку SourceKit-LSP и автодополнение SwiftUI, GitHub-клонирование, настройки темы, терминал в рабочей папке и вывод JPEG внутри контура iPhone. USB-панель и поток логов IDE проверены тестовыми процессами. Зеркало реального iPhone отдельно проверено ранее.
